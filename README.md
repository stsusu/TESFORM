# 센터콘솔 시프터 쇼핑몰 설정 가이드

파일 구성 (전부 같은 폴더, 맨 위에 올리면 됩니다)

- `index.html`, `style.css`, `app.js` : 화면/기능 (건드릴 필요 없음)
- `products.js` : **상품 추가·수정은 여기서**
- `config.js` : 사이트 이름, 배송비, 계좌, 구글폼 연결 정보
- `images/` 폴더 : 상품 사진 (직접 만들어서 올리기)

---

## 1. 구글폼 만들기 (주문 알림용)

1. 구글폼을 새로 만들고 아래 **8개 질문**을 모두 **"단답형"** (주문내역은 **"장문형"**)으로 추가
   1. 주문번호
   2. 이름
   3. 연락처
   4. 주소
   5. 카페닉네임
   6. 추가요청사항
   7. 주문내역 (장문형)
   8. 총 결제금액
2. 폼 오른쪽 위 `⋮` → **미리 채워진 링크 가져오기** → 8칸에 아무 글자나 입력 → **링크 가져오기** → **링크 복사**
3. 복사한 주소를 메모장에 붙여넣으면 이런 모양입니다.
   `https://docs.google.com/forms/d/e/폼아이디/viewform?usp=pp_url&entry.123456=aaa&entry.234567=bbb ...`
4. `config.js`에서
   - `action` 의 `YOUR_FORM_ID` 부분을 위 주소의 **폼아이디**로 교체
   - `entries` 의 `entry.숫자` 를 질문 순서대로 교체
     (입력한 글자 순서대로 이름 → entry 번호가 매칭됩니다)
5. 알림 받기: 구글폼 **응답** 탭 → `⋮` → **새 응답에 대한 이메일 알림 받기**
6. 폼 설정에서 **"로그인 필요 / 응답 1개로 제한"은 꺼두세요** (손님은 로그인 안 하고 주문함)

> 구글폼이 아직 연결 전이면 주문 완료 화면에 "테스트 모드" 안내가 뜨고, 데이터는 전송되지 않습니다.

## 2. 깃허브에 올리기 (GitHub Pages)

1. 깃허브에서 새 저장소(Repository) 만들기 (Public)
2. `Add file → Upload files` 로 위 파일들과 `images` 폴더 올리고 Commit
3. 저장소 `Settings → Pages → Branch: main / (root)` 선택 후 Save
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 에서 접속

## 3. 상품 추가/수정

`products.js` 에서 상품 블록 하나를 복사해 붙여넣고 값만 바꾸면 됩니다.

- `id` : 상품마다 겹치지 않는 영문/숫자
- `price` : 기본 가격
- `options` : 옵션1, 2, 3 ... 자유롭게 추가·삭제
  - 각 선택지의 `add` 는 추가금액 (없으면 0)
- 사진 : `images` 폴더에 올리고 `images: ["images/파일명.jpg"]`
- 옵션을 이미지로 보여주기 : 선택지에 `image` 를 추가
  `{ label: "블랙", add: 0, image: "images/color-black.jpg" }`
  이미지가 있는 선택지는 사진 카드로 보이고, 누르면 위쪽 큰 사진도 그 사진으로 바뀌어요.
  (사진은 정사각형에 가까운 게 좋아요. 일부 선택지에만 넣어도 돼요.)
- 설명 줄바꿈 : `description` 안에서 `\n` 을 쓰면 줄이 바뀌어요. (빈 줄은 `\n\n`)
  `description: "첫 줄입니다.\n둘째 줄입니다.\n\n빈 줄 뒤 셋째 줄입니다.",`
  키보드의 ` (백틱)으로 감싸면 실제로 엔터를 쳐서 여러 줄로 써도 돼요.
- 상세 이미지 : 상품에 `descImages` 를 추가하면 상세 페이지 아래쪽 "상세 정보" 영역에
  사진이 위에서 아래로 쭉 나와요. 가로 860~1000px 사진/긴 상세 이미지를 쓰면 좋아요.
  `descImages: ["images/detail-1.jpg", "images/detail-2.jpg"],`

배송비는 `config.js` 의 `shippingFee` (현재 3000원) 가 총 금액에 자동 합산됩니다.

## 4. 주문 조회 (구글 시트 연동) — 어느 기기에서나 처리상태·배송정보 확인

손님이 이름 + 연락처를 입력하면 최근 주문(최대 10건)의 처리 상태와 택배 정보를 볼 수 있어요.
주소·연락처는 보여주지 않고, 이름은 가려서(김*수) 보여줘요.

1. 구글폼 **응답** 탭 → **스프레드시트에 연결** (이미 했다면 생략)
2. 그 시트 1행(제목 줄) 오른쪽 끝에 열 3개를 만들어요. **제목을 정확히** 적어주세요.
   - `처리상태`
   - `택배사`
   - `송장번호`
3. `처리상태` 열의 2행부터 아래를 선택 → **삽입 → 드롭다운** → 항목 5개를 아래 글자 그대로 추가
   `입금 대기`, `입금 확인`, `제작 중`, `배송 중`, `배송 완료`
   (비워두면 "입금 대기"로 보여요)
4. 시트 메뉴 **확장 프로그램 → Apps Script** → 기본 코드를 지우고 `order-lookup.gs` 내용 전체를 붙여넣고 저장
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 권한 승인 (경고가 뜨면 "고급 → 이동")
6. 나오는 **웹 앱 URL** (`.../exec` 로 끝남)을 복사해서 `config.js` 의 `lookupUrl: ""` 안에 넣고 깃허브에 올려요.

운영할 때는 시트에서 주문 행의 `처리상태`를 바꾸고, 발송하면 `택배사`·`송장번호`를 적으면 돼요.
바로 사이트 조회에 반영됩니다.

주의
- 구글폼 질문 제목이 `주문번호`, `이름`, `연락처`, `주문내역`, `총 결제금액` 과 **똑같아야** 해요.
- Apps Script 코드를 나중에 수정하면 **배포 → 배포 관리 → 수정(연필) → 새 버전**으로 다시 배포해야 반영돼요.
- 시트 자체는 공개되지 않아요. 조회 결과만 스크립트를 통해 나가요.

## 5. 상품 사진 넣기

1. 사진 준비: 파일 이름은 영문 소문자·숫자·하이픈 (예: `basic-1.jpg`), 확장자는 `.jpg`/`.png`
   (아이폰 `.heic`는 안 보임), 가로 1200px 정도, 1MB 이하, 비율 4:3 추천
2. 깃허브 `images` 폴더에 올리기
   - PC: Add file → Upload files → `images` 폴더째 드래그 → Commit
   - 폰: Add file → Create new file → 이름에 `images/readme.txt` 입력 → Commit →
     `images` 폴더로 들어가 Add file → Upload files 로 사진 올리기
3. `products.js` 의 해당 상품 `images: [],` 안에 경로 적기
   `images: ["images/basic-1.jpg", "images/basic-2.jpg"],`
   첫 번째 사진이 목록/장바구니 대표 이미지이고, 2장 이상이면 상세 페이지에 썸네일이 생겨요.
4. 파일 이름은 **대소문자까지 똑같이** 맞춰야 해요. 안 나오면 "IMAGE" 글자만 보여요.

화면이 안 바뀌면 `index.html` 의 `?v=숫자` 를 하나 올려서 다시 올리세요. (캐시 방지)

## 5-1. 로고

- `images/logo-wordmark.png` : 상단 메뉴의 글자 로고 (흰색, 배경 투명)
- `images/logo-full.png` : 메인 화면 큰 로고 (T 마크 + 글자, 흰색, 배경 투명)
- `images/favicon.png` : 브라우저 탭 아이콘
- 로고를 바꾸려면 같은 이름의 파일로 덮어쓰면 돼요. 상단·메인은 검은 배경이라 **흰색 로고**가 잘 보여요.
- 브라우저 탭 제목은 `config.js` 의 `shopName` 을 `"TESFORM"` 으로 바꾸면 돼요.

## 6. 꼭 확인하세요

- 지금 들어있는 상품 3개와 가격은 **샘플**입니다. 실제 상품에 맞게 바꿔주세요.
- 개인정보 동의 문구(보유 기간 등)는 기본 문구입니다. 실제 운영 방식에 맞게 `app.js` 에서 수정하세요.
- 계좌번호는 사이트에 그대로 노출됩니다. (주문 완료 화면에 표시됨)
